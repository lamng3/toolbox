# Examples

Techniques built on top of toolbox. Each one lives in its own folder under
[`examples/`](https://github.com/lamng3/toolbox/tree/main/examples). The folder holds the code,
configs, tests and a README with the method, citation, results and limitations.

| Technique | Area | Source | Example |
| --- | --- | --- | --- |
| Graph model views (GMV): serve GNN outputs as views via L-bisimulation | Graph inference serving | Fan, Lu, Che & Wu, *Approximating Graph Inference by Serving Graph Model Outputs as Views* (2025) | [`examples/gmv`](https://github.com/lamng3/toolbox/tree/main/examples/gmv) |
