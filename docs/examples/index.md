# Examples

Techniques built on top of toolbox. Each one lives in its own folder under
[`examples/`](https://github.com/lamng3/toolbox/tree/main/examples). The folder holds the code,
configs, tests and a README with the method, citation, results and limitations. That README
is rendered here as the example's page, so the two never diverge.

| Technique | Area | Source | Example |
| --- | --- | --- | --- |
| Graph model views (GMV): serve GNN outputs as views via L-bisimulation | Graph inference serving | Fan, Lu, Che & Wu, *Approximating Graph Inference by Serving Graph Model Outputs as Views* (2025) | [GMV](gmv.md) · [code](https://github.com/lamng3/toolbox/tree/main/examples/gmv) |
| Jev decision models: distill debiased or reasoned decisions into one forward pass | LLM decision models | Nokia Applied Research, [AnyJev](https://github.com/nokia-applied-research/AnyJev) (used as a library) | [Jev](jev.md) · [code](https://github.com/lamng3/toolbox/tree/main/examples/jev) |
